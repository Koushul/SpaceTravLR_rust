# Running SpaceTravLR 🍀️


!!! Abstract "Input `.h5ad` | `.X` | `.obsm['spatial']` | `'.obs['cell_type']` " 
    SpaceTravLR requires an input `.h5ad` with gene expression counts in `.X` and cell 2D coordinates in `.obsm['spatial']`. Preferably, the `.obs` would also contain cell type/cluster annotations.
    When no `'cell_type'` is found, SpaceTravLR clusters using `leiden` before training.
    
    See [Auto-Annotation](#auto-annotation) below for cell type label transfer.

!!! info "Preprocessing `.filter_cells` | `.filter_genes` | `PCA` | `HGV` | `log1p` "
    SpaceTravLR can automatically detect if an input dataset needs normalization or filtering. Feel free to use any raw data as input unless you have specific preprocessing requirements.
    
    See [Preprocess](#preprocess) below for the standalone CLI.

!!! tip "Training"
    SpaceTravLR can be trained using an interactive interface and/or via slurm jobs. 
    
    See [Run SpaceTravLR](#run-spacetravlr) below for training details and [Parameters](params.md) for more details about the different hyperparameters available.


!!! Success "Output"
    SpaceTravLR writes artifacts to the specified `output_dir`, along with a `spacetravlr_run_repro.toml` with all the run details and summary for reproducibility. The spatial beta coefficients are stored in `.feather` files, one feather per gene.
    
    For details on output files and artifacts generated by SpaceTravLR, see [Output files](output.md).

**`spacetravlr --help`** and **`spacetravlr-perturb --help`** for all other options.

## Run SpaceTravLR
Launching `spacetravlr` via the commandline will prompt you to specify an input h5ad

```bash
spacetravlr
```

--8<-- "docs/snippets/spacetravlr_tui.html"

You can also run SpaceTravLR with a detailed configuration file. Download an example from [here](runme.toml).
```bash
spacetravlr -c runme.toml
```


You can also specify an input data using `--h5ad` and output path using `--output-dir`.
```bash
spacetravlr --h5ad /storage/tissues/adata.h5ad \
  --output-dir /storage/outputs/spacetravlr_output
```

To launch multiple parallel jobs, use `--join-output-dir`

```bash
spacetravlr --join-output-dir  /storage/outputs/spacetravlr_output
```

`--join-output-dir` allows multiple independent worker GPUs to consume the same input data and parameters sync'ed using `.toml` config file generated by the parent run. SpaceTravLR threads generate unique `.lock` files while a gene is being trained for cross-process coordination. 


## Inspect `.h5ad`

Blazing fast look inside any .h5ad or .h5 without loading the whole object into memory.

```bash
spacetravlr --peek adata.h5ad
```

--8<-- "docs/snippets/peek.html"

Load a single **`obs`** column and print ranked value counts (counts and %).

```bash
spacetravlr --peek path/to/data.h5ad --obs cell_type
```

## UMAP

Plot a UMAP scatter in the terminal.

```bash
spacetravlr --plot-umap path/to/data.h5ad
```

--8<-- "docs/snippets/plotumap.html"

```bash
spacetravlr --h5ad path/to/data.h5ad --plot-umap --obs cell_type
```

```bash
spacetravlr --plot-umap path/to/data.h5ad --leiden
```

## Preprocess
SpaceTravLR reimplements the core Scanpy preprocessing pipeline in pure rust to allow scalable processing of datasets beyond 1 million cells. Optionally, for imputation, a rust version of the MAGIC (Markov Affinity-based Graph Imputation of Cells) algorithm is also built-in.

QC → normalize → HVG → PCA → KNN → UMAP → Leiden / MAGIC.

```bash
spacetravlr --rust-process-h5ad --h5ad adata.h5ad 
```

## Auto-Annotation

Transfers labels from a reference `.h5ad` to a query `.h5ad`

```bash
spacetravlr --map-labels \
  --reference ref.h5ad \
  --query query.h5ad \
  --map-labels-outdir ./malt_out
```

## Aggregate betas

Scan **`*_betadata.feather`** under a run and aggregate β into a multi–cell-type interaction table.

```bash
spacetravlr collect-interactions \
  --run-toml /path/run/spacetravlr_run_repro.toml
```
